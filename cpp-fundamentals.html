C++ Fundamentals — Course Slides

A fifteen-module intro-to-C++ lecture deck for community college students, grounded in a full CS1/CS2 syllabus (Malik's C++ Programming) and simplified for a first-semester audience. Every module builds toward one growing capstone program — a Student Grade & Course Tracker — so students see each new concept, from your first cout to pointers, templates, exceptions, recursion, and linked lists, land in real, working code.

01

How the Course Is Structured

Each module is a self-contained, lecture-ready slide deck (12–14 slides) covering new syntax and concepts, then a Project Build slide that extends the same capstone program, and an in-class exercise to practice before moving on. Modules 1–8 cover a standard CS1 arc (syntax, control flow, functions, collections, and OOP); Modules 9–14 add CS2-level topics — pointers, templates, exception handling, recursion, linked lists, and stacks/queues — that are often skipped in a first course but show up constantly afterward. By Module 15, students have a complete, sorted, file-backed C++ application built entirely from scratch.
