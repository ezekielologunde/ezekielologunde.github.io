C++ Fundamentals — Course Slides

A nine-module intro-to-C++ lecture deck for community college students. Every module builds toward one growing capstone program — a Student Grade & Course Tracker — so students see each new concept land in real, working code.

01

How the Course Is Structured

Each module is a self-contained, lecture-ready slide deck (12–15 slides) covering new syntax and concepts, then a Project Build slide that extends the same capstone program, and an in-class exercise to practice before moving on. By Module 9, students have a complete, file-backed C++ application built entirely from scratch.

02

Download the Modules

Module 1 Start Here
Welcome to C++
The compile pipeline, dev environment setup, program anatomy, and your first Hello World program.
Module 2
Variables, Data Types & Operators
Primitive types, constants, arithmetic/relational/logical operators, and reading input with cin.
Module 3
Control Flow: Decisions & Loops
if/else, switch, for/while/do-while loops, and validating input in a loop.
Module 4
Functions: Organizing Your Code
Pass by value vs. reference, overloading, scope, and refactoring the project into clean functions.
Module 5
Arrays, Vectors & Strings
std::vector, std::string, and scaling from one student to a full class roster.
Module 6
Structs & Introduction to Classes
Encapsulation basics and building the first real Student class.
Module 7
OOP Deep Dive: Encapsulation & Operator Overloading
Getters/setters, const-correctness, static members, and a new Course class.
Module 8
Inheritance & Polymorphism
A GradedActivity base class with Quiz/Exam/Homework, virtual functions, and polymorphic dispatch.
Module 9 Capstone
File I/O, STL Essentials & Final Assembly
Saving/loading the roster to a file, sorting with the STL, and the final project rubric.
